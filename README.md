# Supermarket Sales Prediction — Project 

This repository contains a Jupyter notebook (`supermarket_sales_project.ipynb`) to learn how to build a regression model for supermarket sales data using Pandas, Matplotlib, and scikit-learn.

**Files:**

- supermarket_sales_project.ipynb — the main notebook
- supermarket_model.pkl — generated after training
- supermarket_sales.csv — dataset

**Usage:**

1. Place `supermarket_sales.csv` in the same folder.
3. Install Modules using `pip install -r requirements.txt` .
3. Run the notebook top-to-bottom.
4. The notebook will save a trained model to `supermarket_model.pkl`.
